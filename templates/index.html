Explore o mundo dos números

Os sistemas numéricos são fundamentais para a computação, permitindo representar informações e processar dados. Cada sistema utiliza uma base diferente para representar os valores numéricos.

Começar a converter

Decimal — Base 10

Utiliza dez algarismos, de 0 a 9. É o sistema que usamos no cotidiano.

Binário — Base 2

Utiliza apenas 0 e 1. É essencial para representar dados nos computadores.

Octal — Base 8

Utiliza algarismos de 0 a 7 e pode simplificar a representação de números binários.

Hexadecimal — Base 16

Utiliza algarismos de 0 a 9 e letras de A a F. É bastante utilizado na computação.
